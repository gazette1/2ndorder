# Verification checklist for this package

Built from the go-live-2026-08-01 branch after the TRACE-lite build. Every
check below was run and passed before packaging; re-run any of them to
verify independently. The live site serves the same commit.

## 1. What this package contains

- Full source (src/, server/, web/src/) and docs at the packaged commit.
- The fresh grid-capex run (data/runs/grid-capex) generated on the TRACE
  prompt, plus its counter-scenario run. This is the primary demo run.
- The other demo runs (pharma reshoring, battery storage, water pair),
  generated before TRACE; they render without the new sections by design.
- No secrets: built by git archive from tracked files only. .env is not in
  the repo; .env.example documents every variable.

## 2. TRACE-lite checks (the new build)

Open data/runs/grid-capex/decompose.json and confirm:
- "trigger" carries actor, action, magnitude (quantified, $40-60B range),
  geography, timing, certainty, reversibility.
- "reactions" has 5 entries; each names an actor, incentive, likelyResponse.
- Every node in "nodes" has non-empty "kpi" and "falsifier" (12 of 12).

Open data/runs/grid-capex/dossiers.json and confirm on any entry:
- reality.positionUSD is 36750000 and reality.positionBasis is
  "25 bps of $14.7B AUM".
- reality.ownershipPct is present; sub-$400MM names carry a flag reading
  "position would be N percent of the company".
- expectations carries priceChange3moPct, pct52wRange, psRatio, and the
  proxies note.

In the app (sign in, open the grid-capex run):
- Trigger strip renders under the seed as labeled readout items.
- "Who reacts" table sits between the map and the candidates.
- Map node cards show "KPI: ..." chips; selecting a node shows "Breaks if:".
- Composite column shows bands (Strong / Moderate / Weak / Insufficient
  evidence), numeric in the tooltip.
- A dossier shows the Expectations block and the ownership line; the
  days-to-build caption reads "assumes a 25 bps of $14.7B AUM position".
- Open an OLD run (Reshoring of pharmaceutical...): no trigger strip, no
  reactions table, no KPI chips. Bands still apply. Nothing crashes.

Export IC memo on grid-capex and confirm sections: Trigger, Who reacts,
KPI and falsifier lines in the map table, Expectations proxies and
Fund-scale investability per name.

## 3. Standing checks (unchanged behavior)

- /healthz returns ok; / serves the landing; /app the sign-in.
- Sign-in requires an allowlisted email plus the passcode; a wrong passcode
  or unlisted email is refused with a plain message.
- Every dossier block carries a provenance tag; stubs say stub; caps say
  delayed price x reported shares; the earnings-language block says press
  releases, not call transcripts.
- Counter-scenario on grid-capex opens the bear run (on-site generation
  meets data center load; utility capex flatlines).
- Stocks tab: "olin" returns Olin Corp first; an uncarded real ticker
  offers the read-its-10-K-now button.

## 5. Known open items (stated, not hidden)

- The counter-scenario run in this package was generated by the same TRACE
  prompt; if its own trigger/reactions look thinner than the base run's,
  that is model variance, not a code path difference.
- Expectations are proxies from delayed data, not consensus estimates.
- Coverage (sell-side) remains a stub without a key and is labeled so.
- Single-tenant preview: all signed-in users see all runs. Do not enter a
  proprietary thesis into the shared instance; the demo uses public
  scenarios by design.
- Run latency is 45-50 minutes end to end; the app renders stages
  progressively (map ~2 min, candidates ~4 min).
